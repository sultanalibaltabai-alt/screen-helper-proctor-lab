# Screen Helper + Proctor Lab

[Инструкция на русском — начать здесь](README_RU.md)

Download **StudyTools-Windows-x64.zip** from the [latest release](https://github.com/sultanalibaltabai-alt/screen-helper-proctor-lab/releases/latest), extract everything and run **Start.cmd**. The source ZIP does not include compiled executables. Use your own Gemini key or funded OpenAI key; no key is distributed.

Screen Helper 8.3 displays only elapsed seconds while waiting and shows the answer for 15 seconds. API keys use Windows user-scoped DPAPI encryption. Ordinary requests do not save recognized questions, screenshots or answer history. See [security details](docs/SECURITY_RU.md).

See [OpenAI setup](docs/OPENAI_5_USD_RU.md), [handoff prompt](docs/PROMPT_FOR_CHATGPT_RU.md), and [verification status](docs/PROJECT_STATE_RU.md). Windows x64 only. Proctor Lab is an independent training tool, not OES.
