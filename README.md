# Screen Helper + Proctor Lab

[Инструкция на русском — начать здесь](README_RU.md)

Download **ScreenHelper-Windows-x64.zip** from the [latest release](https://github.com/sultanalibaltabai-alt/screen-helper-proctor-lab/releases/latest), extract everything and run **ScreenHelper/Start.cmd**. **StudyTools-Windows-x64.zip** also includes Proctor Lab. The source ZIP does not contain executables. Provider keys are never distributed; shared mode uses the owner's server key, direct mode uses your own key.

Screen Helper 8.4 supports full answers, MSQ, matching, ordering, fill-in blanks, code and drag/drop instructions. It shows only elapsed seconds while waiting and displays a scrollable result for 15 seconds. New installs use the shared gateway without a provider key on each PC. **The gateway is deployed but its model is intentionally disabled until the owner configures a funded key.** Direct Gemini/OpenAI profiles remain available. See [cloud setup](docs/CLOUD_OWNER_RU.md) and [security details](docs/SECURITY_RU.md).

See [OpenAI setup](docs/OPENAI_5_USD_RU.md), [handoff prompt](docs/PROMPT_FOR_CHATGPT_RU.md), and [verification status](docs/PROJECT_STATE_RU.md). Windows x64 only. Proctor Lab is an independent training tool, not OES.
