# Screen Helper + Proctor Lab — готовые инструменты для Windows

Для запуска на другом ПК откройте [готовый релиз](https://github.com/sultanalibaltabai-alt/screen-helper-proctor-lab/releases/latest)
и скачайте **StudyTools-Windows-x64.zip**.
Зелёная кнопка Code → Download ZIP скачивает исходники: в них нет готового EXE.

1. Войдите в свой GitHub, если репозиторий приватный, и скачайте архив релиза.
2. Распакуйте весь архив в обычную папку. Запустите `Start.cmd`.
3. В меню: **5 — Gemini** с ключом Google; **1 — OpenAI** с доступным API-балансом.
   Сохраните настройки. Затем **2 — панель**, проверьте AI на контрольном вопросе
   и нажмите «Запустить помощник».
4. Для учебного прокторинга запустите Proctor Lab и следуйте его окну.

Python на компьютере, использующем готовый релиз, не нужен. Нужны Windows x64,
доступ к интернету и доступная квота Gemini либо API-баланс OpenAI. Локальный Proctor Lab
не требует AI-ключа. Это не приложение для Android/iOS/macOS.

## Что входит

- `screen-helper/`: исходники помощника — снимок только по горячей клавише,
  OpenAI Responses API или Gemini, 1–8 вопросов, проверка меток вариантов,
  локальные алгоритмы графов, общий тайм-аут, отмена и панель диагностики.
- `proctor-lab/`: тренировочный сайт, расширение и компонент Windows.
  Контролируются заданные процессы, дисплеи, активное приложение, некоторые окна
  поверх других, изменения буфера/съёмных дисков; присутствие и количество лиц,
  уровень звука, добровольная локальная запись.
- `docs/OPENAI_5_USD_RU.md`: настройка API и оплаты простыми шагами.
- `docs/PROMPT_FOR_CHATGPT_RU.md`: готовый промпт для следующего ChatGPT/Codex.
- `docs/PROJECT_STATE_RU.md`: что проверено и что ещё не подтверждено.
- `Build-Release.ps1`: воспроизводимая сборка; GitHub Actions может собрать её вручную.

Screen Helper 8.3: во время ожидания выводится только число секунд; ответ виден
15 секунд. Временный бессрочный показ и подробные этапы на экране удалены.
Ошибки обозначаются `?`, объяснение находится в панели. Ctrl+Alt+S — снимок,
Ctrl+Alt+X — отмена, Ctrl+Alt+H — скрыть, Ctrl+Alt+Q — завершить.

API-ключ шифруется Windows DPAPI для текущей учётной записи и хранится в
`config.local.json`; Gemini и OpenAI имеют отдельные зашифрованные профили.
Он не встроен в GitHub, EXE или архив. На другом ПК ключ нужно ввести заново.
Учёт Codex этого чата не используется для запросов приложения.
Старый открытый ключ автоматически шифруется при чтении этой версией.
Старая версия программы после такой миграции этот конфиг уже не прочитает:
распаковывайте обновление в новую папку, введите ключ заново и завершите старую
копию через Ctrl+Alt+Q перед запуском новой. Не копируйте EXE отдельно от `_internal`.

В обычном режиме вопросы, снимки и история ответов на диск не записываются.
Подробные проверки API запускаются отдельно вручную. О защите и её пределах:
[SECURITY_RU.md](docs/SECURITY_RU.md).

## Начальная настройка OpenAI

Подробности в [инструкции](docs/OPENAI_5_USD_RU.md). Готовый релиз уже поддерживает
OpenAI: переписывать программу после покупки API-кредитов не требуется.
Новая настройка `Setup-OpenAI.cmd` выбирает `gpt-5.4-mini` и OpenAI.
Доступность выбранной модели для конкретного оплаченного ключа проверяет контрольный вызов.

## Разработка

Windows x64, Python 3.13, Node.js 24, Git.

```powershell
python -m pip install -r requirements-build.txt
.\Build-Release.ps1
```

Ни один автономный тест не использует настоящий ключ или снимок рабочего стола.
Готовые файлы появятся в `release/`. `python scripts/verify_release.py` проверяет
целостность, контрольные суммы и отсутствие обнаруживаемых ключей/личных отчётов.
Проверка конкретного оплаченного ключа
выполняется отдельно владельцем через ApiTest.cmd / панель.

Proctor Lab не является OES. Обнаружение и работа в этом стенде не доказывают
совместимость или незаметность для другого прокторинга. Он намеренно фиксирует
ScreenHelper и может блокировать начало строгого теста. Проект не скрывает процессы
из Диспетчера задач и не завершает посторонние программы.
