# Screen Helper 8.5 + Proctor Lab

Готовые файлы: https://github.com/sultanalibaltabai-alt/screen-helper-proctor-lab/releases/latest

Для одного помощника скачайте **ScreenHelper-Windows-x64.zip**. Распакуйте весь
архив, откройте папку ScreenHelper и запустите **Start.cmd**. Python не нужен.
Для помощника вместе с учебным прокторингом есть **StudyTools-Windows-x64.zip**:
его Start.cmd открывает меню. Code → Download ZIP скачивает исходники без EXE.

## Полные ответы

Поддержаны MCQ, MSQ/чекбоксы, текст, число, верно/неверно, сопоставление, порядок,
заполнение пропусков, код и drag-and-drop как пары «элемент → место». Ответ
показывается белым текстом без рамки снизу слева на 15 секунд. Длинный ответ делится
на страницы: Ctrl+Alt+F8 показывает следующую без нового запроса. На белом фоне
белый текст плохо виден всем, включая вас; запись экрана может его захватить. Во время ожидания — только
число секунд. Кнопки сайта автоматически не нажимаются и элементы не перетаскиваются.
Вопросы вне изображения не видны. Это поддержка форматов, не гарантия правильности.

## Без ключа на каждом ПК

Новая установка выбирает общий сервис автоматически:
https://study-tools-cloud-sultan-1109.satinwaterlily4.chatgpt.site

**Gemini подключён. Контрольный запрос через готовый EXE и общий сервер дал B) 4
за 4,28 секунды, HTTP 200.** Модель может временно перегружаться; это не гарантия
доступности и правильности каждого ответа. Тот же ZIP подключается с другого
Windows x64 ПК без личного ключа провайдера. $5 — общий расходуемый API-баланс,
не безлимит. Ключ не встраивается в EXE и GitHub. Сервер выдаёт ограниченный токен
установки автоматически, хранит его хеш и контролирует общую квоту.
[Инструкция владельцу сервера](docs/CLOUD_OWNER_RU.md).

Со своим ключом: Setup-Gemini.cmd или Setup-OpenAI.cmd. Вернуться в общий режим —
Setup-Cloud.cmd. Проверка и диагностика — Control.cmd. В общем меню: 2 — панель,
5 — свой Gemini, 1 — свой OpenAI, 6 — общий сервис, 3 — Proctor Lab.
Проверка AI на примере 2+2 может расходовать квоту/баланс.

Ctrl+Alt+S — снимок по вашему действию; Ctrl+Alt+X — отмена; Ctrl+Alt+H — скрыть;
Ctrl+Alt+F8 — повтор/следующая страница результата без запроса; Ctrl+Alt+Q — завершить.
Перед обновлением завершите старую копию и распакуйте новую отдельно.

## Состав и проверка

screen-helper/ — клиент Windows, локальные алгоритмы графов, DPAPI, диагностика.
cloud-gateway/ — очищенные исходники облачного сервиса; runtime secrets отсутствуют.
proctor-lab/ — независимый учебный сайт, расширение и компонент Windows.
docs/CLOUD_OWNER_RU.md — подключение общей модели один раз владельцем.
docs/PROMPT_FOR_CHATGPT_RU.md — передача следующему ChatGPT/Codex.
docs/PROJECT_STATE_RU.md — фактические проверки и ограничения.

Сборка из исходников: Windows x64, Python 3.13, Node 24. Сначала установите зависимости
requirements-build.txt, затем запустите Build-Release.ps1. Он проверяет согласованность
контракта клиента и сервера, запускает автономные тесты и собирает portable ZIP.
scripts/verify_release.py проверяет ZIP, SHA-256 и отсутствие обнаруживаемых ключей.
Секреты, локальные конфиги, отчёты и пользовательские снимки не публикуются.

Собственные ключи и токен установки защищены Windows DPAPI. В обычном режиме
клиент и сервер не сохраняют изображения, вопросы или историю ответов. Общий
сервис имеет квоты; подробности и пределы защиты — docs/SECURITY_RU.md.
Proctor Lab намеренно может обнаруживать и блокировать ScreenHelper. Работа в
нашем стенде не доказывает совместимость с OES. Процессы не скрываются.
