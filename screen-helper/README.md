# Screen Helper 8.4 — полные ответы и общий сервис

Готовая версия: Windows 10/11 x64, интернет, распакованный ZIP целиком.
Python устанавливать не нужно. EXE должен оставаться вместе с _internal.

## Запуск без личного API-ключа

Запустите Start.cmd. Новая установка автоматически выбирает общий облачный сервис.
Ctrl+Alt+S снимает выбранное окно/монитор и отправляет изображение по вашему действию.
В ожидании выводится только число секунд. Полный ответ открывается в читаемом окне
с прокруткой на 15 секунд. Ctrl+Alt+F8 повторяет показ без нового API-запроса.

ВАЖНО: общий сервис подготовлен, но владелец ещё не добавил ключ и оплату.
До этого он сообщает «модель не подключена». Покупка $5 сама по себе не включает
сервер: владелец один раз добавляет ключ как секрет Sites и включает сервис.
После этого тем же ZIP можно пользоваться на других ПК без личного API-ключа.
Статус: https://study-tools-cloud-sultan-1109.satinwaterlily4.chatgpt.site/health

## Собственный ключ тоже поддерживается

Setup-Gemini.cmd — ваш ключ Google. Setup-OpenAI.cmd — ваш ключ OpenAI с API-балансом.
Setup-Cloud.cmd — вернуться к общему сервису. Control.cmd — настройки, состояние,
кнопка проверки AI и запуск/остановка помощника. Контрольный API-тест может расходовать
квоту/баланс; он использует рисунок с вопросом 2+2, не снимок рабочего стола.

## Форматы ответов

Один вариант MCQ, несколько вариантов MSQ (включая чекбоксы без букв), свободный
текст, числа, верно/неверно, сопоставления, порядок, drag-and-drop как пары
«элемент → место», заполнение пропусков и код. Программа показывает ответ, а не
перетаскивает элементы и не заполняет тест за пользователя. Поддержка формата
не гарантирует правильность решения. Видны только 1–8 полных вопросов на снимке;
скрытые страницы и недостающие условия не выдумываются. Неоднозначность — ?.
Локальные графовые алгоритмы продолжают перепроверять распознанный граф.

Ctrl+Alt+X — отмена ожидания; Ctrl+Alt+H — скрыть результат; Ctrl+Alt+Q — завершить.
При ошибке показывается ?, объяснение находится в панели. Завершите старую копию
через Ctrl+Alt+Q перед запуском новой. Обновление распаковывайте в отдельную папку.

Собственные ключи и автоматически полученный токен установки шифруются Windows DPAPI.
В ZIP нет общего ключа провайдера. Не публикуйте config.local.json, cloud-session.local.json
или другие локальные настройки. На другом ПК собственный API-ключ вводится заново;
общий сервис регистрирует новую установку автоматически. Старый открытый конфиг
при чтении новой версией шифруется; старые версии после этого его не понимают.

Обычный режим не записывает снимки, распознанные вопросы или историю ответов на диск.
Общий сервис хранит только технические записи авторизации и квот. Проверка сертификатов
HTTPS сохранена, перенаправления API запрещены. Программа видна системе и не
гарантирует работу или незаметность в OES. Учебный Proctor Lab может её обнаруживать.
