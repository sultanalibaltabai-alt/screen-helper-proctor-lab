# Screen Helper 8.3 — Gemini и OpenAI

Готовая переносимая версия предназначена для Windows x64. Распакуйте весь ZIP,
оставьте EXE вместе с `_internal`. Python устанавливать не нужно.

1. С ключом Google запустите **Setup-Gemini.cmd**. С ключом OpenAI и доступным
   API-балансом — **Setup-OpenAI.cmd**. Сохраните настройки.
2. Откройте **Control.cmd**, нажмите «Проверить AI». Проверка на вопросе 2 + 2
   использует API; возможен расход квоты/баланса. Рабочий стол не снимается.
3. После успешной проверки нажмите «Запустить помощник».
4. **Ctrl+Alt+S** снимает выбранное окно или монитор и отправляет изображение
   выбранному API. Ожидание показывается только числом секунд. Ответ виден 15 секунд.

Ctrl+Alt+X — отменить локальное ожидание; Ctrl+Alt+H — скрыть показ;
Ctrl+Alt+F8 — повторить показ последнего результата без нового запроса;
Ctrl+Alt+Q — завершить помощник. При ошибке появляется `?`: причина находится
в панели. Отмена скрывает индикатор. Запуск не выводит уведомление поверх экрана.

Ключи шифруются Windows DPAPI для текущей учётной записи. Gemini и OpenAI имеют
раздельные профили. На другом компьютере ключ вводится заново; встроенного ключа
или переноса лимита Codex нет. Настройку выбранного сервиса можно открыть повторно.

Общий лимит запроса — 60 секунд по умолчанию, допустимо 5–180. Одновременные
управляемые запросы блокируются. Для временного серверного сбоя допускается один
повтор внутри общего лимита. При 429 или ошибке ключа повторов нет. После перегрузки
действует пауза. Резерв не назначается автоматически; явный резерв — отдельная
настройка. Локальная отмена не гарантирует отмену оплаты у провайдера.

В обычном режиме вопросы, снимки и история ответов на диск не сохраняются.
Файл last-result.json содержит только технические сведения и код ошибки.
HTTPS проверяет сертификаты, перенаправления API запрещены. В отдельных проверках
на синтетических заданиях сохраняются диагностические отчёты без ключа.

**Обновление:** завершите старую копию Ctrl+Alt+Q, распакуйте новую в отдельную папку
и введите ключ заново. Старый открытый конфиг, если читать его новой версией,
автоматически шифруется; прежняя версия после миграции этот конфиг не поймёт.
Не загружайте локальные конфиги/отчёты или пользовательские снимки в GitHub.

Основные модели: Gemini `gemini-3.8-flash`, OpenAI `gpt-5.4-mini`.
Модель и поддерживаемый ею режим рассуждений можно выбрать в настройках.
Код сохраняет точные локальные расчёты графовых задач после распознавания.
Неоднозначные/незавершённые ответы не угадываются. Доступность модели, её скорость
и точность для конкретного ключа подтверждаются отдельной реальной проверкой.
Автономные тесты используют синтетические изображения и имитацию API.
