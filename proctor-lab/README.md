# Proctor Lab 3 · браузер и Windows

Веб-исправление 3.0.1 устраняет Illegal invocation: стандартный fetch вызывается
с контекстом Window. Компонент Windows 3.0.0 совместим, замена EXE не требуется.
В диагностике есть реальная проверка HTTP-вызова с заведомо неверным кодом (401).
Для локального стенда обновите файлы web из новой переносимой сборки; для сайта
обновите страницу. Добавлена регрессионная проверка контекста браузерного fetch.

Новая версия добавляет отдельный Windows-компонент, локальную модель присутствия
и количества лиц (MediaPipe BlazeFace) и добровольную локальную запись выбранных
медиаисточников. Это учебный стенд, не копия OES и не система доверенной аттестации.

1. Распакуйте весь `proctor-lab-windows-v3.zip`, запустите `ProctorLabAgent.exe`.
2. В окне компонента включите разрешение контроля. До этого датчики не опрашиваются.
3. Нажмите «Скопировать код» и «Открыть локальный стенд».
4. Вставьте код в поле сайта, нажмите «Подключить Windows» и включите требование
   компонента. Код действует до закрытия программы, не сохраняется сайтом и не
   добавляется в URL. Локальный стенд и модель доступны без интернета.
5. Для полного набора браузерных событий вручную установите учебное расширение
   из `extension/` / ZIP на сайте. Камеру, микрофон и весь экран подключайте явно.
6. Пресет максимальных условий включает все источники и локальную запись.
   Если программа из списка уже найдена, строгий сеанс не начнётся. Новое
   обнаружение во время сеанса ставит его на паузу. Никакие процессы не завершаются.
7. Журнал страницы скачивается в JSON, журнал Windows — кнопкой в приложении.
   Локальные видео скачиваются отдельно после остановки. Закрытие вкладки теряет
   несохранённое видео. Закрытие компонента немедленно прекращает его работу.

Контролируемые Windows API: Toolhelp32 (имена процессов), EnumDisplayMonitors,
GetForegroundWindow, EnumWindows (прозрачные TOPMOST окна), GetClipboardSequenceNumber
(без содержимого), GetLogicalDrives/GetDriveType (съёмные диски). Это не полный
перечень всех USB-устройств. Имена неизвестных/переименованных программ не определяют
их назначение. Для удалённого доступа и захвата используется явный список в
`native/windows_sensors.py`, в том числе `ScreenHelper.exe`.

Сервис слушает только 127.0.0.1:8771, проверяет Host, Origin и временный Bearer-код;
нет автозапуска, системного сервиса, драйвера, изменения настроек защиты или ключей API.
При потере heartbeat контроль сеанса заканчивается через 15 секунд. На HTTPS-сайте
браузер может отдельно запросить доступ к локальной сети; если связь блокируется,
используйте локальную страницу из кнопки приложения. Она не требует ослабления
проверок TLS или браузерной защиты.

Модель различает отсутствие и число лиц; это не идентификация личности,
определение живости, направления взгляда или гарантированный детектор телефона.
Звук измеряется по RMS, не выполняется распознавание речи. Диагностика на
`diagnostics.html` проверяет реальную модель без камеры и отдельно правила паузы.
Запись через MediaRecorder добровольная, хранится только в памяти вкладки,
ограничена временем работы до 10 минут. Видео и наблюдения не отправляются серверу.
Цепочка хешей Windows-журнала не является удалённым удостоверением: владелец ПК
контролирует программу и итоговый файл. Нет гарантии обнаружения всех скриншотов.

Для сборки Windows: Python 3.11+, PyInstaller. `python native/package_native.py`
проверяет наличие собранного EXE и включает копию веб-стенда с моделью; Python
на компьютере, использующем готовый архив, не нужен. Исходники — в `native/`.

Проверки: `npm test`, `python -m unittest discover -s native -q`,
`python native/agent.py --self-check`. Оффлайн-тесты не заменяют проверку реальной
камеры, звука, демонстрации и воспроизведения получившихся файлов на конкретном ПК.

Ниже сохранено описание прежней версии; её ограничения «только браузер» относятся
к режиму без нового подключённого компонента Windows, а отсутствие записи —
к режиму с выключенным флажком записи.

# Proctor Lab

Контроль целостности включён по умолчанию: MutationObserver замечает изменение
вопросов и новые исполняемые SCRIPT-элементы. Канонические вопросы восстанавливаются,
программное change-событие не записывает ответ. В строгом режиме сигнал скрывает
вопросы; продолжение требует ручной проверки. CSP основной страницы запрещает
inline-JavaScript, сторонние источники скриптов, OBJECT и изменение базового URL.
Наблюдатель SCRIPT сообщает об изменении; сам по себе он не отменяет уже выполненный
код. CSP не является универсальной блокировкой расширений или программ ОС.

Блок «Проверка скриптов на стенде»: начать сеанс → начать пробу → выполнить действие
проверяемой программой → закончить пробу. Отчёт JSON schemaVersion 3 содержит probes,
сигналы и явные границы наблюдения. Сайт не проверяет, запускалась ли программа,
и не получает её снимков. Отсутствие событий не называется обходом защиты.
«Проверить датчики» предлагает контрольную подмену вопроса, программное событие
ответа и вставку безвредного inline-скрипта. Действия создают замечания намеренно.
Не смешивайте их с отдельной пробой внешней программы.

Страница `assistant.html` работает в современных браузерах телефонов и компьютеров:
ручная загрузка снимка, Gemini с рассуждениями, просмотр/исправление распознанного
графа и локальный пересчёт. Ключ не сохраняется, запрос идёт напрямую Google API;
сервер сайта ключа и изображения не получает. Проверено вычислительное ядро;
сетевой вызов из браузера зависит от CORS/сети и проверяется пользователем со своим ключом.
Максимальный пресет включает полный экран, расширение, строгую паузу, камеру,
микрофон и демонстрацию всего экрана. Разрешения выдаются только вручную по кнопке.
Окно/вкладка вместо всего монитора не проходят проверку выбранного режима.
Это не детектор всех процессов ОС и не защита от владельца компьютера.

Тренировочный стенд на русском языке. Статический сайт без сервера и без зависимостей.
Публикуется папка `dist/`. Основной стенд работает без API-ключа;
страница assistant.html отдельно принимает ключ Google для выбранного запроса.

## Поведение

Версия 2: 18 задач ДАА — Крускал/Прим, Дейкстра/Беллман—Форд, DAG/Кан/BFS.
Три работы по два варианта, схемы графов и пояснения после завершения.
Старые математические примеры сохранены как отдельная работа.

«Строгая пауза» скрывает вопросы при уходе со страницы, потере фокуса, выходе
из полного экрана, попытке копирования или остановке выбранных источников.
Таймер продолжает идти; продолжение доступно после восстановления условий.

Расширение Manifest V3 лежит в `extension/`, ZIP доступен на сайте. Его нужно
установить вручную из распакованной папки, затем обновить страницу. Оно добавляет
события создания/переключения вкладок, навигации и ухода из окна экзамена.
Режим возврата к вкладке включается отдельно. Оно не закрывает другие вкладки,
не сохраняет их адреса и содержимое, не отправляет журналы в сеть.
Меню расширения позволяет немедленно остановить контроль; watchdog — 90 секунд.
Без расширения снимки экрана и системные процессы по-прежнему не обнаруживаются.
С расширением также нет гарантии обнаружения программ Windows или системных снимков.
Сайт и мост сообщений изменяемы владельцем ПК: это учебный стенд, не защищённая
система реальной аттестации и не криптографически удостоверенный журнал.

- 1, 2 или 3 одновременно видимых вопроса с эталонными ответами из примера.
- Таймер, обязательный полный экран по выбору и завершение с оценкой.
- Активный сеанс фиксирует `blur/focus`, `visibilitychange`, `fullscreenchange`,
  попытки копирования/вырезания/вставки/контекстного меню и реально полученные клавиши.
- Попытки операций буфера обмена могут предотвращаться страницей.
- Камера, микрофон и демонстрация экрана — только после выбора флажков и отдельной
  кнопки подключения. Для них требуется HTTPS или localhost и поддержка браузера.
  Только локальные превью и индикатор громкости; записи и загрузки отсутствуют.
- Источники останавливаются при завершении, уходе со страницы и изменении их выбора.
- Журнал в памяти вкладки и экспорт JSON. Нет хранения на сервере или localStorage.

Это симулятор браузерных сигналов, а не копия OES. Он не перечисляет процессы и
расширения, не блокирует системные команды, не распознаёт лица или речь. Отсутствие
событий не доказывает незаметность сторонних программ. Захват экрана при демонстрации
может показывать стороннее окно; экран не анализируется и не записывается сайтом.

Для сравнения повторяйте один и тот же сценарий: обычный сеанс, затем сеанс с
проверяемой программой. Сравните журналы, не смешивая выводы со свойствами OES.
Проверка в этом стенде не подтверждает работу в реальном экзамене.

## Проверки исходников

```powershell
npm test
node --check dist/app.js
```

Для просмотра локально можно использовать любой HTTP-сервер с корнем `dist/`.
Страница использует ES-модули и не должна открываться напрямую через `file://`.
Публикация по HTTPS обеспечивает доступ к устройствам с разрешения посетителя.
