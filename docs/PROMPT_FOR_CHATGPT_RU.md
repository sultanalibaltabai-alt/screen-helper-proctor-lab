# Промпт для следующего ChatGPT / Codex

Скопируй текст ниже в новый чат. Если у AI есть доступ к GitHub или файлам,
прикрепи этот репозиторий. В обычном текстовом ChatGPT попроси вести тебя по шагам.
Ключ API в чат не присылай.

---

Помоги мне закончить настройку собственного OpenAI API в готовом Windows-проекте
Screen Helper + Proctor Lab. Я плохо разбираюсь в API. Объясняй просто и делай
доступную техническую работу сам. Проект уже реализован — не переписывай его с нуля.

Моя цель: скачать готовый ZIP из GitHub Releases на другой Windows x64 компьютер,
распаковать, запустить Start.cmd, один раз ввести мой API-ключ локально и работать.
Python на целевом компьютере устанавливаться не должен. Начальный бюджет API — $5;
это расходуемый баланс, а не безлимит. Покупку кредитов и создание ключа я выполню
сам в своём аккаунте. Не проси прислать ключ, платёжные данные или коды входа в чат.

В версии 8.3 Gemini настраивается через Setup-Gemini.cmd, OpenAI — через
Setup-OpenAI.cmd. Если я выбираю Gemini, не требуй оплатить OpenAI. Ключи защищены
Windows DPAPI и хранятся отдельно по провайдерам. На другом ПК их вводят заново.
В ожидании выводится только число секунд, ответ виден 15 секунд. Подробные этапы
и бессрочный показ удалены; не возвращай их без отдельной просьбы.

Сначала прочитай README_RU.md, AGENTS.md, docs/PROJECT_STATE_RU.md,
docs/SECURITY_RU.md и docs/OPENAI_5_USD_RU.md. Репозиторий содержит:

- screen-helper/helper.py: OpenAI Responses API, настройка --configure-openai,
  обработка ошибок, снимок по горячей клавише, выдача подтверждённого результата;
- screen-helper/answers.py: JSON-контракт вопросов и меток вариантов;
- screen-helper/graph_solver.py: точные вычисления поддерживаемых графовых задач;
- screen-helper/inference.py и routing.py: отменяемый процесс запроса, общий лимит
  времени, кэш одинакового снимка и ограниченные повторы;
- screen-helper/panel.py и Setup-OpenAI.cmd: окно настройки и проверка AI;
- screen-helper/config_store.py: DPAPI, атомарное сохранение и миграция ключей;
- proctor-lab/: независимый тренировочный сайт, расширение и Windows-компонент;
- Build-Release.ps1 и scripts/package_project.py: сборка переносимых ZIP;
- .github/workflows/build.yml: ручная сборка в GitHub Actions.

В подготовленной версии OpenAI-профиль использует gpt-5.4-mini, image input и
строгий JSON в POST https://api.openai.com/v1/responses, store=false. Для этой модели
режимы fast/balanced/deep передают reasoning.effort low/medium/high. Нельзя переносить
эти параметры на любую другую модель без проверки её документации. Gemini сохранён
отдельным вариантом. Живого ключа OpenAI при передаче не было: пройденные mocked
HTTP-тесты не доказывают доступность оплаченного сервиса или точность ответов.

Порядок действий:

1. Уточни только наличие уже пополненного API-проекта, не сам ключ. Если оплаты
   ещё нет, дай короткую инструкцию входа в OpenAI Platform → Billing → пополнение
   на $5, если сумма доступна. Не покупай подписку ChatGPT вместо настройки API.
   Проверь актуальные официальные правила и цены; не выдумывай количество ответов.
2. Помоги мне создать ключ в своём проекте самостоятельно и вставить его только
   в локальное окно Setup-OpenAI.cmd. Весь код подключения уже есть. Не встраивай
   ключ в EXE, репозиторий, release, URL, логи или промпт. На другом ПК ключ вводится
   заново; перенос моего чата/недельного лимита Codex в программу не требуется.
3. Предложи один контрольный запрос через панель / ApiTest.cmd: синтетическое
   изображение 2 + 2, правильный вариант B, без захвата моего рабочего стола.
   Отдельно сообщи, если возможен расход API. Не называй тест успешным до настоящего
   завершённого ответа. В api-check.json должны быть ok=true, время и используемая модель.
4. При ошибке сначала различай 401, 403, 404, 429 rate limit, insufficient_quota,
   503 и сетевой тайм-аут. Не обещай, что новый ключ исправляет баланс/квоту.
   Не выключай защиту сети, TLS-проверку или прокторинг. Не подставляй случайные буквы.
5. Если запрос успешен, проверь один пример с двумя/тремя вопросами с эталонами,
   объясни пределы проверки. В графах сохраняй направления и веса, точные локальные
   вычисления и отказ при неоднозначности. Не обещай стопроцентную точность.
6. Если код действительно потребуется менять, запускай подходящие автономные тесты,
   пересобери Windows portable релиз и обнови release-asset. Не заставляй меня ставить
   Python на целевом ПК. Не публикуй локальные конфиги и пользовательские снимки.

Proctor Lab может намеренно фиксировать ScreenHelper.exe и блокировать строгий
учебный сеанс. Это отдельная функция стенда, а не ошибка OpenAI. Режим допуска
с журналированием, обсуждавшийся раньше, не реализован в этой передаче. Не выдавай
его за существующий и не скрывай обнаружение из отчёта. Нет обещания работы в OES,
скрытия из Диспетчера задач или эквивалентности нашего стенда реальному прокторингу.

В конце дай мне три понятных пункта: какой архив скачать, что запустить и какой
результат контрольного теста подтверждён. Отдельно назови всё, что ещё не проверено.
