  синтетического видеопотока, Windows-датчики и обнаружение ScreenHelper по имени.
- Веб-стенд опубликован отдельно через Sites; GitHub не заменяет его хостинг.
  Готовый Windows-релиз содержит автономную локальную копию сайта и модель.
- При полной сборке из чистой экспортной папки прошли 75 тестов помощника,
  28 тестов сайта и 8 тестов native-компонента.
- Оба готовых EXE из распакованного общего ZIP прошли автономную проверку:
  ScreenHelper 8.2 — интерфейс, горячие клавиши, формат ответа и дочерний процесс;
  ProctorLabAgent 3.0.0 — датчики Windows без ошибок. API и снимок рабочего стола
  при проверке не использовались. Это проверка на текущем ноутбуке.
- Проверены целостность всех четырёх ZIP, SHA-256 и отсутствие обнаруженных
  API-ключей, локальных конфигов и личных отчётов в исходниках/архивах.

Не подтверждено: живой запрос с оплаченным OpenAI-ключом; точность на произвольных
университетских вопросах; работа на каждом чужом ПК; эквивалентность или обход OES.
Оффлайн-тесты используют поддельные ключи и имитацию API.

Намеренные ограничения: процесс ScreenHelper виден системе и заносится в список
стенда; строгий режим может не пустить к тесту. Отдельного режима допуска с журналом
пока нет. Нет драйвера, автозапуска, антиспуфинга личности, универсального детектора
скриншотов или защиты от владельца компьютера. Все источники включаются явно.

Следующий необходимый шаг для владельца: пополнить доступный API-проект,
самостоятельно создать ключ, ввести его локально и выполнить один платный контрольный
запрос. Промпт и пошаговая инструкция находятся рядом в docs/.
