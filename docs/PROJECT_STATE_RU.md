# Состояние передачи · 8 ноября 2026

Screen Helper 8.3:

- Gemini и OpenAI имеют отдельные настройки и зашифрованные Windows DPAPI ключи.
  Старый открытый ключ мигрирует; на другом ПК ключ вводится заново.
- Ожидание — только число секунд, ответ — 15 секунд. Временные режимы подробного
  статуса и бессрочного показа удалены. Ошибка — `?`, причина в панели.
- Обычный режим не сохраняет вопросы, снимки или историю ответов на диск.
- HTTPS с проверкой сертификата; API-перенаправления запрещены. Общий лимит
  5–180 секунд, по умолчанию 60. Резерв больше не назначается автоматически.
- Gemini, OpenAI Responses, локальные алгоритмы графов, отмена, ограниченные
  повторы и контроль одновременных запросов сохранены.
- 84 автономных теста помощника прошли, включая настоящий локальный DPAPI,
  восстановление конфигурации, таймер и отказ от перенаправления на локальном сервере.

Proctor Lab 3.0.0, веб-исправление 3.0.1 остаются отдельным учебным стендом.
Ранее проверены модель лиц на 0/1/2 лицах, синтетическая запись/воспроизведение,
датчики Windows и обнаружение ScreenHelper. Строгий стенд может блокировать его;
режима скрытия процессов или обхода OES нет. Полная сборка также запускает
28 тестов сайта и 8 тестов native-компонента.

Полная сборка прошла 120 тестов: 84 помощника, 28 сайта и 8 native-компонента.
Оба готовых EXE из распакованного StudyTools-Windows-x64.zip прошли отдельную
автономную проверку на текущем ноутбуке. ScreenHelper 8.3 подтвердил настоящий
DPAPI, таймер 15 секунд, горячие клавиши и дочерний процесс. ProctorLabAgent
подтвердил датчики Windows без ошибок. API и снимки рабочего стола не использовались.
Архивы проходят проверку ZIP, SHA-256 и поиск ключей/локальных конфигов/личных отчётов.
Живые запросы к Gemini и OpenAI для версии 8.3 при этой передаче не выполнялись.
Нет проверки на втором физическом ПК и гарантии точности на любых вопросах.
Инструкции по оплате OpenAI, безопасности и промпт для следующего чата — в docs/.
