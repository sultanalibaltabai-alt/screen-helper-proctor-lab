# OpenAI API: настройка с начальным бюджетом $5

Программа уже содержит подключение OpenAI. Покупается расходуемый API-баланс,
а не «отдельный ИИ за пять долларов». Количество ответов заранее неизвестно:
учитываются изображение, текст, размер ответа и рассуждения модели.

## Что сделать владельцу аккаунта

1. Откройте [OpenAI Platform](https://platform.openai.com/) и войдите в свой аккаунт.
2. Перейдите в [Billing](https://platform.openai.com/settings/organization/billing/overview).
   Добавьте способ оплаты и выберите пополнение на $5, если эта сумма доступна
   в вашем кабинете. Перед оплатой проверьте итоговую сумму и возможные налоги.
   Если предлагается автоматическое пополнение, оставьте его выключенным для
   ограниченного пробного бюджета. Платёж выполняете вы; программа его не делает.
3. Создайте отдельный проект для этой программы и собственный ключ в
   [API keys](https://platform.openai.com/api-keys). Скопируйте полный секретный ключ.
   Создание ключа и ввод платёжных данных выполняет владелец аккаунта.
4. В скачанном релизе запустите `ScreenHelper/Setup-OpenAI.cmd` либо выберите
   настройку OpenAI в `Start.cmd`. Вставьте ключ в окно программы и сохраните.
   Сервис OpenAI и модель `gpt-5.4-mini` уже выбраны. Код менять не требуется.
5. Откройте панель `ScreenHelper/Control.cmd`, нажмите «Проверить AI».
   Это один контрольный пример 2 + 2, ожидаемый ответ B; возможен расход API.
   Рабочий стол в этой проверке не снимается. Успех означает, что этот ключ,
   сеть и выбранная модель ответили на этот пример, а не на любой будущий вопрос.
6. При успехе нажмите «Запустить помощник». Ctrl+Alt+S отправляет выбранное окно
   или монитор в API, Ctrl+Alt+X отменяет локальное ожидание, Ctrl+Alt+Q завершает
   помощник. Панель показывает этап и время. Снимок отправляется только по команде.

Платный API-запрос проходит прямо от приложения к `https://api.openai.com/v1/responses`.
Ключ передаётся в заголовке Authorization. GitHub и сайт Proctor Lab его не получают.
Снимок отправляется OpenAI; проверьте, что в нём нет лишних личных данных.
Ключ шифруется средствами Windows DPAPI для текущей учётной записи и сохраняется
локально в config.local.json. Этот файл нельзя публиковать или
копировать в чат. На новом ПК ключ вводится заново; в публичном EXE его нет.

## Стоимость и контроль расходов

На 7 ноября 2026 года официальная страница GPT-5.4 mini указывает $0.75 за миллион
входных и $4.50 за миллион выходных текстовых токенов. Изображение также учитывается
по правилам vision; точный расход зависит от запроса. Рассуждения увеличивают
расход и время. Поддержка и доступность модели для вашего ключа проверяются API.

В last-result.json / api-check.json программа показывает возвращённые API числа
токенов. Это не остаток баланса. Смотрите реальные расходы в
[Usage](https://platform.openai.com/usage) и Billing. Уведомление о бюджете не следует
считать гарантированным денежным стопом. Другие устройства с тем же аккаунтом/ключом
тоже расходуют баланс. Отмена локального ожидания не гарантирует отмену уже принятой
работы на стороне провайдера. Не запускайте многократные проверки без необходимости.

Лимит Codex в этом чате не используется как ключ приложения. Наличие подписки или
кредитов ChatGPT само по себе не подтверждает доступный баланс конкретного API-проекта.
Если аккаунт предлагает API-кредиты, проверьте их применение непосредственно в Billing.

## Если вместо ответа ошибка

| Сообщение | Что проверить |
| --- | --- |
| key / 401 | Полный ключ OpenAI, без маскирующих звёздочек и пробелов |
| billing/quota | Доступный баланс и оплату API-проекта; новый ключ не создаёт деньги |
| rate limit / 429 | Дождаться восстановления лимита частоты, не создавать поток повторов |
| access / 403 | Разрешения ключа и проекта |
| model / 404 | Точное имя модели и её доступность в вашем аккаунте |
| timeout / connection / DNS / TLS | Сеть и доступность API; не отключать проверку сертификатов |
| incomplete / ? | Полноту и читаемость вопроса; это не подтверждённый ответ |

Не используйте чужие ключи и не отправляйте свой ключ следующему ChatGPT.
Для помощи достаточно названия ошибки и безопасного отчёта без секретов.
До покупки ключа автономные тесты проходят с имитацией API. Живой оплаченный
OpenAI-запрос в текущей передаче проекта не проверялся.

Официальные источники: [модель и цены](https://developers.openai.com/api/docs/models/gpt-5.4-mini),
[изображения](https://developers.openai.com/api/docs/guides/images-vision),
[структурированный вывод](https://developers.openai.com/api/docs/guides/structured-outputs).
